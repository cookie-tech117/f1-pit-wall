# 这一圈，由你决定 · PIT WALL

融媒体课程项目：基于真实大奖赛案例的 F1 进站策略挑战。

## 网站内容
- 393 × 852 手机界面，米白、赛车红配色。
- 三道策略题、六个历史结果页，完整交互流程。
- 点选 A 或 B 后，选中的选项变红，再确认进入结果。
- 黑色结果标题显示“决策前位置 → 最终名次”。
- 支持历史选择记录、策略总结和分享卡保存。

## GitHub Pages 发布
本项目是纯静态网站，无需安装依赖或构建。
将本压缩包解压后的全部文件上传至仓库根目录（index.html 必须位于根目录）。
在仓库 Settings → Pages 中选择 Deploy from a branch，选 main 分支和 / (root)，点击 Save。
完成部署后，Pages 会显示网站访问地址。
